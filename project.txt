# MASTER BUILD PROMPT — CUSTOMIZABLE PERSONAL BROWSER WORKSPACE EXTENSION

Act as a senior browser-extension engineer, product designer, frontend architect and UX specialist.

Your task is to design and build a production-quality, fully functional browser extension that transforms the browser's default New Tab page into a personalized productivity workspace.

I have attached reference screenshots of an existing product called ORBIT. Use them strictly as functional references to understand the desired features and interactions. DO NOT copy its branding, exact layouts, color palette, visual identity, or theme designs. Create an original product with a significantly better visual experience.

The goal is to build a complete working product, not a static prototype or a collection of non-functional UI components.

==================================================
1. PRODUCT VISION
==================================================

Build a customizable personal browser workspace that allows users to:

- Personalize their browser's New Tab page.
- Create multiple independent workspaces.
- Add, remove, hide and rearrange widgets.
- Drag and resize dashboard components.
- Organize website shortcuts into collections.
- Customize wallpapers, colors, typography and appearance.
- Manage daily tasks and productivity.
- Switch between completely different visual themes.
- Export and import their workspace configurations.
- Store their information locally without requiring registration.

The product should feel like a premium, modern desktop productivity application embedded inside a browser.

Target browsers:
- Google Chrome
- Microsoft Edge

Use Chrome Extension Manifest V3.
